Телеграм-бот с вакансиями в Корее. Монетизация: контакты работодателя
скрыты, доступ к ним платный (5 000 вон).

## Как запускать

```bash
pip install -r requirements.txt
python main.py          # бот
python admin.py         # веб-админка (нужен flask, см. ниже)
```

Деплой: Railway, `Procfile` → `worker: python main.py`, Python 3.11.9.

## Реальная структура (README устарел — не верить ему)

README описывает `bot/`, `db/`, `admin/`, `data/`. **Этих папок нет.**
Все файлы лежат плоско в корне.

| Файл | Статус |
|---|---|
| `main.py` | **единственный рабочий файл.** Монолит: БД + клавиатуры + хэндлеры + запуск |
| `handlers.py`, `keyboards.py`, `database.py` | **мёртвый код.** Импортируют `bot.keyboards` и `db.database` — таких модулей нет, упадут при импорте |
| `app.py` | старая админка без авторизации, `debug=True`. Не использовать |
| `admin.py` | актуальная админка: Basic Auth, `debug=False` |

**Правило: правки бота вносить в `main.py`.** Прежде чем менять
`handlers.py`/`database.py`/`app.py` — уточнить у владельца, не проще ли
их удалить. Дубликаты уже разошлись: в `database.py` схема другая
(таблицы `payments` и `purchased`), в `main.py` — `purchases`.

## Известные проблемы (не выдуманные — проверены по коду)

Порядок по влиянию на деньги и данные:

1. **Оплата фиктивная.** `main.py:247` — по кнопке «✅ Подтвердить оплату»
   вызывается `add_purchase()` без какой-либо проверки платежа. Любой
   пользователь получает контакты бесплатно в два клика. Монетизации
   фактически нет.
2. **База стирается при каждом редеплое.** `main.py:21` → `DB_PATH = 'jobs.db'`,
   относительный путь на эфемерной ФС Railway. Все пользователи и покупки
   теряются. Нужен volume или внешняя БД (Postgres).
3. **Пагинация не работает.** Кнопки шлют `page_{city}_{n}`, но хэндлера
   на `page_` в `main.py` нет. Всегда видны только первые 5 вакансий
   (`vacancies[:5]`), остальные недоступны.
4. **`flask` отсутствует в `requirements.txt`** — админка на хостинге не
   поднимется.
5. **Пароль админки захардкожен** как дефолт: `admin.py:11`,
   `ADMIN_PASSWORD` по умолчанию `korea2024`. Задать через окружение.
6. **`CONTACT_PRICE` из `.env` не используется** — «5 000 вон» вписано
   строками в 4 местах `main.py`. Менять цену придётся правкой кода.
7. **Состояние в памяти процесса.** `flood_storage`, `user_city_filter`,
   `user_vacancies_cache` (`main.py:149-151`) — теряются при рестарте и
   растут без очистки (утечка памяти на дистанции).
8. **`show_contacts` не проверяет покупку** (`main.py:255`) — в отличие от
   `buy_contacts`. Выдаёт контакты по callback без проверки прав.
