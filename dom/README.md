# ДОМ — частная вилла · Нячанг

Премиальный консьерж-сервис в образе высококлассной виллы. Каждое направление — комната Дома, каждый ИИ-агент — член персонала.

| Комната | Направление |
|---|---|
| **Холл** | Fast Track в аэропорту Камрань, трансфер Maybach / DCar |
| **Покои** | Вилла-резорты и Wellness: Amanoi, Six Senses, L'Alya, Gran Meliá, Vinpearl |
| **Обеденный зал** | Fine Dining, приватные шефы, закрытые ивенты |
| **Причал** | Яхтинг: Emperor Cruises, Ana Marina, Nemo Yacht |
| **Терраса** | Гольф, вертолётные чартеры, дайвинг в Хон Мун |

| Персонал | Роль |
|---|---|
| **Управляющий** | Агент-Аналитик: обход комнат (аудит), расчёт пребывания, предложения гостю |
| **Мажордом** | Агент-Планировщик: сценарий пребывания по дням |
| **Голос Дома** | Агент-Контентмейкер: посты для соцсетей |

## Запуск за 3 шага

```bash
cd dom
pip install -r requirements.txt
cp .env.example .env        # откройте .env и вставьте ANTHROPIC_API_KEY
python main.py
```

Ключ API: https://console.anthropic.com → API Keys.
Расчёт пребывания (пункт 2) и список комнат (пункт 6) работают **без ключа**.

## Меню

| Пункт | Что делает | Результат |
|---|---|---|
| 1 | Обход Дома: риски, узкие места и несоответствия стандарту по комнатам. Можно подключить отзывы и логи из `inputs/` | `reports/…_audit.md` |
| 2 | Собрать пребывание: себестоимость, цена B2C для гостя, B2B для агентств, маржа + приглашение в Дом (текст КП) через Claude | `reports/…_package.csv` (открывается в Excel), `…_kp.md` |
| 3 | Предложение гостю: «Гостевое крыло», «Хозяйская сюита», «Весь Дом» — со строками для расчёта | `reports/…_usp.md` |
| 4 | Сценарий пребывания по дням и комнатам с планом Б (Мажордом) | `reports/…_plan.md` |
| 5 | Пост для соцсетей (Голос Дома) | `reports/…_post.md` |
| 6 | Комнаты Дома, партнёры и их id | в терминале |

Пример ввода для пункта 2:
```
amanoi-villa 5
maybach-transfer 2
cxr-fasttrack-arrival 2
nemo-yacht-sunset 1
```
Количество считается в единицах прайса: ночи, часы, люди или поездки.

## 3D-витрина для гостей (`web/`)

Вилла над заливом в 3D: камера перелетает по комнатам, ползунок меняет время суток (рассвет из моря, закат за виллой, ночью горят окна и бассейн), есть звук прибоя и цикад. Гость собирает пребывание, видит цену и копирует заявку менеджеру.

- Открыть: `web/index.html` в браузере (нужен интернет для 3D-библиотеки и шрифтов).
- После изменения цен в `data/`: `python web/build_site.py` — витрина обновится.
- Гостю показываются только B2C-цены и стандарты. B2B-цены и риски не попадают на сайт.

## Как обновлять комнаты

Файл комнаты содержит `room_name`, `room_description` и список партнёров `providers`. Каждая услуга:

```json
{
  "id": "amanoi-villa",
  "provider_name": "Amanoi",
  "service_type": "Вилла с бассейном",
  "pricing_b2b": {"amount": 1600, "currency": "USD", "unit": "per_night"},
  "pricing_b2c": {"amount": 2100, "currency": "USD", "unit": "per_night"},
  "price_verified": false,
  "service_standards": ["..."],
  "risk_factors": ["..."]
}
```

- `pricing_b2b` — сколько вы платите партнёру; `pricing_b2c` — розничная цена для гостя.
- `unit`: `per_trip`, `per_night`, `per_hour`, `per_person`, `per_booking`, `per_event`.
- ⚠ **Все цены в базе сейчас примерные** (`price_verified: false`). Замените их на цены из договоров с партнёрами и поставьте `true`.
- Новая услуга — скопируйте блок в нужную комнату, поменяйте `id` (он должен быть уникальным). Ошибки в базе показываются при запуске.

## Настройки (`config.py`)

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `CONCIERGE_FEE_PCT` | 10 | сервисный сбор Дома сверх B2C-цены |
| `AGENT_COMMISSION_PCT` | 15 | скидка турагентствам от цены гостя |
| `MIN_MARGIN_PCT` | 20 | ниже этой маржи — предупреждение |
| `CLAUDE_MODEL` (в .env) | `claude-opus-5` | модель |
| `CLAUDE_EFFORT` (в .env) | `high` | глубина анализа: `low` дешевле и быстрее |
