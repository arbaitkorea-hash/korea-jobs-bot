# Сайт «ДОМ» — запуск за 15 минут

Готовый одностраничный сайт. Ничего устанавливать не нужно.

```
site/
├── index.html      # сайт
├── og-image.png    # картинка превью ссылки в Telegram / WhatsApp / соцсетях
├── favicon.svg     # иконка во вкладке
├── robots.txt      # для поисковиков
└── sitemap.xml     # карта сайта
```

## Шаг 1. Впишите свои данные (5 мин)

Откройте `index.html` в любом редакторе (Блокнот, TextEdit, VS Code):

1. **Контакты** — в самом низу файла, блок `CONFIG`:
   ```js
   whatsapp: "84901234567",   // ваш номер, только цифры
   telegram: "dom_nhatrang",  // ваш Telegram без @
   ```
   После этого кнопка «Отправить запрос» будет открывать WhatsApp с готовым текстом заявки.
2. **Домен** — замените `https://example.com/` на ваш домен во всех файлах (поиск и замена: `example.com` → `вашдомен.com`). Встречается в `index.html`, `robots.txt`, `sitemap.xml`.

## Шаг 2. Опубликуйте (5 мин, бесплатно)

**Netlify (проще всего):**
1. Зайдите на https://app.netlify.com/drop
2. Перетащите папку `site` в окно браузера.
3. Сайт сразу доступен по адресу вида `xxx.netlify.app`.
4. Свой домен: Site settings → Domain management → Add a domain, затем пропишите DNS у регистратора по подсказке Netlify. HTTPS включается автоматически.

## Шаг 3. Подключите поисковики (5 мин)

- **Яндекс Вебмастер** (главный для русскоязычной аудитории): https://webmaster.yandex.ru → добавить сайт → подтвердить → «Файлы sitemap» → `https://вашдомен.com/sitemap.xml`.
- **Google Search Console**: https://search.google.com/search-console → добавить ресурс → отправить sitemap.
- Проверить превью ссылки: отправьте ссылку себе в Telegram.

## Что уже сделано для SEO

- Заголовок и описание страницы под запросы «VIP отдых Нячанг», «трансфер Камрань Maybach», «аренда яхты Нячанг», «Amanoi», «Six Senses Ninh Van Bay».
- Разметка Schema.org: турагентство (TravelAgency) и блок вопросов (FAQPage) — Google и Яндекс могут показать ответы прямо в выдаче.
- Open Graph: красивое превью при отправке ссылки в мессенджеры.
- Правильная структура заголовков, быстрая загрузка (без тяжёлых библиотек), мобильная версия.
