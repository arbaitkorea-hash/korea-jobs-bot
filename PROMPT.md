- Историю git не переписывать. Причина — в `HANDOFF.md`, «Чего НЕ делать».

## Как работать

- Проверяй результат **в браузере**, а не только сборкой. Два серьёзных бага
  сборка и линтер пропустили: нерабочий скрипт темы и битые корейские адреса.
- Показывай скриншоты после изменений в интерфейсе.
- В коде комментируй **причину** решения, а не пересказ кода. Прежде чем
  предлагать переделку — прочти комментарий рядом: почти у каждого неочевидного
  места есть обоснование, и оно, как правило, стоило дорого.
- Коммиты по-русски, осмысленные, пуш в рабочую ветку.
- Не сочиняй за художника «историю работы» — это его голос. Не переводи тексты
  машинно между языками. Не обрезай изображения работ. Не меняй `slug` у
  опубликованных работ. Не предлагай 3D-зал. Не обновляй Prisma до 7.

## Команды

```bash
npm run dev         # разработка (http://localhost:3000)
npm run build       # прод-сборка
npm run lint        # eslint
npm run db:migrate  # prisma migrate dev
npm run db:seed     # демо-данные (для разработки)
npm run db:import   # реальный каталог из prisma/catalog.json
npm run db:studio   # просмотр БД
```

Если база не отвечает — в контейнере она иногда не поднята:
`service postgresql start`.
